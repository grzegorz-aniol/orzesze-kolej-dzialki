# Linie kolejowe 140 i 169: działki w Orzeszu

Nieoficjalne zestawienie działek w Orzeszu objętych postępowaniem o ustalenie lokalizacji linii kolejowej (znaki sprawy IFXIII.747.33.2026 i IFXIII.747.35.2026, Wojewoda Śląski): mapa, orientacyjne adresy i wyjaśnienia.

Strona: https://grzegorz-aniol.github.io/orzesze-kolej-dzialki/

Dane: `dane/dzialki.csv`, `dane/dzialki.geojson`. Źródła: GUGiK (ULDK, PRG), podkład mapy © OpenStreetMap.

Zestawienie może zawierać błędy. Wiążące są wyłącznie obwieszczenia i akta sprawy.
